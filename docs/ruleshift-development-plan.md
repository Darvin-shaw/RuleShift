日期：2026-09-07。用户要求更新 README 并开始 W1 开发；每项二级任务验收后提交推送。

## 范围（GOV-01）

输入：问题、待判断命题、业务事实、目标时间、多版本规程。
输出：支持／否定／无法确定、适用版本、证据片段、决定性条件／例外、缺失事实、修订影响。
历史合规判断与“按新版重新评估”的情景问题分开处理；缺少事实不等于否定。
来源冲突单独标注，根据已核验的适用与替代关系处理，不能简单选最新版本或投票。
首个场景仅为制造业不合格品处置与放行；图片、跨行业迁移和基础模型训练不在 W1 范围。

## 排期与数据科学性

W1：2026-09-07 至 09-13，完成 GOV-01～04 的技术交付。
用户最新约定：本周任务验收、推送后暂停开发；后续阶段须用户另行启动。
W2–3 数据与试标；W4–5 抽取、对齐、基线；W6–7 推理与对照；
W8 集成；W9–10 实验与试点。授权与专家资源属于独立依赖。
先 50 条试标、再 200 条人工核验样本，600 条为扩展目标，不承诺尚未取得的权威集规模。
文档族、文档版本、条款片段、问答条数分别统计。
自然修订、合成修订、真实企业案例分别报告；受限集未取得时标记“未评估”。
同族版本、近重复及其派生问答不得跨训练／测试集；测试冻结先于模型调优。
模型生成标签只能作为候选，人的许可、评审和实验成绩不得模拟。
与时间过滤强基线比较；报告成对一致性、引用支持、拒答覆盖率、错误率、复核召回与成本。
前期讨论的百分比为待基线校准的目标，不能写为保证或实测。
