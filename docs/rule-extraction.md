# 规则抽取

运行 `python -B scripts/extract_rules.py clause.txt`，输入为 UTF-8 单条规程，输出 JSON。
不支持的句式返回非零退出码，末尾换行可以保留。

## 支持范围

- `条件时允许放行，否则禁止放行。`
- `条件时允许放行；但例外时禁止放行。`
- `检验合格时允许放行；但例外时禁止放行。检验不合格时禁止放行。`

条件支持中文括号、`且`、`或` 和前缀 `并非`。优先级为括号、否定、且、或。
逻辑词是保留分隔符，含这些字的普通词语不适合直接输入。最多 4000 字、32 层括号。

## 输出

`condition` 为条件树，操作符为 `atom/group/not/and/or`；`exceptions` 为禁止放行的例外条件。
节点 `text` 和 `span` 对应原文，跨度为 Python 字符索引、左闭右开，不是字节位置。
`outcome` 记录允许放行的位置，`otherwise` 只在原文明确提供兜底规则时填写。

原子条件保留原文，不推断数值或业务字段；“不超过3”不会被拆成逻辑否定。
模块不执行事实判断，不使用参考标签，不改变 W3 冻结模型。受控句式解析不代表通用中文
规则抽取或真实语料验收，检索与语义推理仍待后续开发。

`extract_document(text)` 接受以换行分隔的多条规则，所有跨度均相对完整输入。
`exception_outcomes` 与 `otherwise_evidence` 分别保留例外结果和兜底结果的原文位置。
递归深度最多 64，括号最多 32 层；不支持的复合连接词（如“或者”）明确拒绝。
批量运行与版本对齐见 [W4 使用说明](w4-development.md)。
