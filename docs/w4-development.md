# W4：规则抽取与版本对齐

## 运行

Python 3.12+，在仓库根目录执行：

```bash
python -B scripts/run_w4.py
```

默认读取已登记的 W3 原创样本，对每族相邻版本抽取并对齐，报告写入
`data/generated/w4-report.json`。报告包含原文位置、对应关系、未匹配条款、候选及输入和代码哈希。
默认样本为 5 族、10 版本，输出 5 个版本对：4 项修改、1 项措辞变化，无不支持条款。
这是开发回归结果，不是自然修订语料上的泛化指标；W3 冻结模型和测试报告不被改写。

## 配置与输入

使用 `--config configs/w4.json` 指定配置。字段如下：

| 字段 | 含义 |
|---|---|
| `source` | 已通过研究用途准入的登记文件，路径相对仓库根目录 |
| `output` | 报告路径，必须在 `data/generated/` 内 |
| `similarity_threshold` | 文字候选的最低相似度，范围 (0, 1]，默认 0.65 |

默认输入沿用现有 `families[].versions[]`，按列表顺序比较相邻版本；调用者应按修订顺序排列。
每个版本可提供 `text`（单条款）或 `clauses`（含唯一 `id`、`text` 的条款列表）。
单条款模式沿用规程族 ID 作为稳定条款标识；多条款模式的相同 ID 必须确实表示同一条款。
也可输入 `{"old": [...], "new": [...]}`，两个列表采用相同的条款格式。
自定义文件须先完成[来源登记](source-registry.md)；库函数 `align(old, new)` 可直接处理内存数据。

每版最多 100 条款，每条款最多 10000 字。条款内的独立规则以换行分隔，
单条规则的语法与限制见[抽取接口](rule-extraction.md)。非法配置返回 1；
存在不支持条款时仍保存报告并返回 2，不能将部分解析误当作全部成功。

## 对齐方法

1. 比较条件树、结果、例外与兜底规则；仅消除括号、布尔同类嵌套、重复项和次序差异。
   对“复检评分至少 N 分／达到 N 分”进行限定的同义归一，数值仍参与比较。
2. 唯一结构相同的条款标为 `unchanged` 或 `wording`。重复结构不任意选取对应项。
3. 完整有序规则序列可唯一对应到相邻 2–4 条款时，标为 `split` 或 `merge`。
   该规则识别条款边界调整，不推断任意文本改写中的语义拆合。
4. 剩余相同稳定 ID 的条款按结构差异标为 `modified`，相同结构仍标为不变或措辞变化。
5. 剩余条款使用标准库 `SequenceMatcher` 产生文字候选；关闭 autojunk，双向分数取平均。
   候选不升级为确定对应关系，未匹配也不自动解释为新增或废止。

序列比较的行为与限制参考 [Python difflib 文档](https://docs.python.org/3/library/difflib.html)。
此处采用成熟的结构归一和序列匹配方法，无模型下载和新增依赖；相似度不是语义等价证明。

## 验收范围

| 任务 | W4 交付 |
|---|---|
| NLP-01 | 原文字符跨度、嵌套且／或、前缀否定、禁止例外、兜底引用、多行条款及拒绝处理 |
| NLP-02 | 不变、限定措辞变化、稳定 ID 修改、结构拆分／合并、歧义保留与文字候选 |
| 运行与回归 | 注册来源准入、配置 CLI、逐条报告、答案隔离、越界输出拒绝及全量回归 |
