## 建议与剩余条件

1. 中文主任务继续以原创样本验证工程；官方题录只作为版本核验入口。
   在取得可用正文、用途许可和领域复核前，不宣称有真实中文多版本评测集。
2. 后续若启动辅助实验，优先评估 ContractNLI 的 NLI／例外与证据任务，
   再评估 ShARC 的补问任务；英文结果单独报告，不混入中文制造业指标。
3. 启用任一外部数据前，记录固定发布版本、许可、精确文件哈希、来源及上游血缘，
   逐项审核 research/model_input/training/external_model/redistribution，
   然后按来源登记接口导入；当前外部五项用途均未获项目批准。
4. DATA-01 本轮完成来源可行性研究，真实材料授权准入仍未完成。
   没有找到可在本轮直接宣告完成的“中文制造业多版本＋专家标签＋明确用途权限”数据库。

按用户要求，W2 收尾后暂停；本记录不触发数据下载、模型训练或 W3 开发。
