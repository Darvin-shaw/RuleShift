# W3 离线基线与冻结评测

W3 验收范围为合成数据去重、按族冻结、无需外部服务的基线模型及可复现报告。
多数类模型仅使用 train 标签；规则文本模型只读取条文、事实、命题和目标日期。
不训练或调用 LLM。预设标签是机器参考答案，评测只说明合成任务上的工程一致性。

## 冻结方案

5 个规程族、10 个版本、25 对／50 条判断。每族 5 个相关事实组合。
threshold、exception 为 train（20 条），score 为 dev（10 条），approval、waiver 为 test（20 条）。
共享复检条款的 approval、waiver 保持在同一测试分区；W2 是 W3 的上游工程样本，不作为另一训练集。
同族版本、派生问答不跨分区。冻结文件记录原始数据 SHA-256、任务数及完整族划分。
冻结后修改原文或标签时评测拒绝继续；如需改数据，应先创建新版本并重建基线。

## 运行与配置

在仓库根目录执行 `python -B scripts/run_w3_eval.py`；其他目录使用脚本绝对路径。
`--config` 指定 JSON 文件；其中路径统一相对仓库根目录，绝对路径亦可。
默认配置见 `configs/w3-eval.json`；split 只接受 train/dev/test，models 只接受 majority/rule_text。
修改 split、模型集合或输出路径不改冻结内容。报告包含输入及冻结哈希、模型代码哈希、逐题预测、
准确率、macro-F1、混淆矩阵、双版本均正确率、应变／不应变判定准确率、作答覆盖率、
作答错误率及原文证据匹配率。无样本可统计的指标为 null。

原文证据匹配只检查引用是否包含参考片段，不等于语义蕴含证明。
规则解析只覆盖本试验集的阈值、例外、且／或模板；未知文本或日期不适用时返回无法确定。
候选转存脚本 `ai_annotate.py` 是机器参考标签导出器，不是预测模型；其输出不能作为独立预测评测。
报告保存在 `data/generated/`，受 Git 忽略；公开汇总需注明数据、配置和代码版本。

## W3 验收结果（2026-09-08）

使用 v2 数据、仓库默认配置及同批提交的模型代码：测试集 20 条判断／10 对。
多数类准确率 0.35、macro-F1 0.1728395、成对准确率 0.20；规则文本基线三项均为 1.0。
规则基线覆盖已知模板，这不是盲测，也不能证明跨领域泛化。W3 工程范围完成，W4 起暂停。
