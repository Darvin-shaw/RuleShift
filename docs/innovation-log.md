# 创新提案台账

本台账记录已经汇报的创新点及其处理状态。详细流程和提案模板见
[`docs/innovation-process.md`](innovation-process.md)。

## 状态定义

- `候选`：已记录，尚未决定是否进入开发。
- `已批准`：已确认纳入 WBS，尚未完成验收。
- `暂缓`：有价值但当前资源、依赖或时机不满足。
- `拒绝`：经评估不纳入，并保留原因。
- `已完成`：实现、验证和联动更新均已完成。
