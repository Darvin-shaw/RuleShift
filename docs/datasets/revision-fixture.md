# DATA-02 自编修订样本

日期：2026-09-08；来源：SYN-REV-001；类别：S；版本：1。

## 目标与验收

以确定性生成器构造三个原创规程族：阈值收紧、新增例外、仅措辞变化。
每族两个版本、四组相同事实的版本对照，共 6 个文档版本、12 对／24 个候选判断。
覆盖支持、否定、无法确定，以及结论应变和不应变。每个版本是一条完整条款。
运行 `python -B scripts/generate_revision_fixture.py --check` 检查产物可复现；
单测检查独立预期标签、证据引用、版本时间和事实保持一致。

## 格式与边界

公开文件：`data/public/SYN-REV-001.json`。顶层包含 `schema_version`、`source_id`、
`families`；每族包含 `family_id`、`revision_type`、`split`、`versions`、`pairs`。
版本包含 ID、生效日期及完整条文；每对包含 ID、事实、命题、预期变化及两个判断。
判断保存版本 ID、目标时间、候选标签、完整条款证据和缺失事实。
时间区间为左闭右开，最后版本截止时间为 null；这里比较各版本生效时的判断，
不把新版回溯应用到旧日期。日期及规程全部虚构。

样本由编码助手原创，采用 MIT；无第三方原文、企业信息或外部模型调用。
登记自检身份为 `codex:technical-fixture`，不是人工审批或专家标注。
用途沿用 W1：研究、本地模型输入、再分发允许；训练和外部模型输入禁止。
所有族的 split 均为 `technical_fixture`，不得混入训练、验证、冻结测试集。
标签仅为程序构造的候选，DATA-03 双人标注与领域裁决尚未进行。
无自然修订样本，不代表行业规则或真实 NLP 效果。DATA-01 来源核验仍独立待办。

## 使用

生成：`python -B scripts/generate_revision_fixture.py`（只更新样本，不自动修改准入哈希）。
若内容变化，审阅差异后更新来源登记的 SHA-256，并重跑准入与发布检查。
实现沿用已批准的 INNO-2026-002 和 DATA-02，不新增依赖或改变研究范围。
